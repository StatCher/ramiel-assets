# Источники

- **0.0.17: SProps Workshop Edition**, ID 173482196, материал `sprops/textures/sprops_chrome`. Параметры сверены с VMT в установленном GMA: собственные diffuse/normal, Phong 6/3/[.25 1 4], env_cubemap. Текстуры аддона не включены в архив; чип обращается к установленному SProps и создаёт отдельный материал с синим `$color2`/`$envmaptint`. При отсутствии SProps используется собственная синяя текстура 0.0.16. Параметры модели/шейдера дополнительно сверены с первичным [Source SDK VertexLitGeneric](https://github.com/ValveSoftware/source-sdk-2013/blob/master/src/materialsystem/stdshaders/vertexlitgeneric_dx9.cpp).

- **0.0.16**: численные ключи и иерархия четырёх состояний реконструированы из C4D-урока (06:30–28:45), а первая фаза и длина шипов адаптированы по пользовательским записям/скриншотам. Повороты сверены с [Matrix Manual Maxon](https://developers.maxon.net/docs/py/2023_2/manuals/data_algorithms/classic_api/matrix.html). Собственные CSG-данные генерируются через manifold3d 3.5.5 (Apache-2.0, https://github.com/elalish/manifold). Новые vfx_crystal.png и vfx_pressure.png — собственные цвет/маска; vfx_beam.png содержит RGB-рисунок по trace_01 Kenney CC0 с отдельной непрозрачной альфой. vfx_beam_glow.png сохраняет прежнюю CC0-производную маску. shot.ogg: исходный непрерывный фрагмент 1,5–14,3 s, натуральная скорость, 12,8 s, Vorbis mono 32 kbit/s; CC0 к аудио не относится.
- **0.0.16: прямой рендер корпуса**: [ENTITY:GetRenderMesh](https://wiki.facepunch.com/gmod/ENTITY:GetRenderMesh), [PostDrawOpaqueRenderables](https://wiki.facepunch.com/gmod/GM:PostDrawOpaqueRenderables), [IMesh:Draw](https://wiki.facepunch.com/gmod/IMesh:Draw). HUD-гейт и сигнатуры дополнительно проверены по обоим локальным SDK.

- **0.0.15: дополнительные Kenney Particle Pack / CC0**, тот же источник и commit зеркала, что ниже: trace_01.png, light_03.png, muzzle_01.png. Оригиналы сохранены в source-assets/kenney. prepare_assets.py версии готовит true-RGBA маски: поворот/кадрирование следа в полосу 256×64 с мягкими краями, маску короны 256×256 с мягким заполнением центра, маску плавления 256×256. Файлы vfx_beam/vfx_charge/vfx_melt соответственно 4440 / 23132 / 21850 байт. Новая дорожка shot.ogg — та же пользовательская аниме-дорожка: хвост после 6,5 секунды растянут atempo, Vorbis с ограничением 24 kbit/s, 16,94 сек / 55435 байт; CC0 к звуку не относится.
- **0.0.15: настройки Source**, первичные справочники: https://wiki.facepunch.com/gmod/Enums/EF (NOSHADOW=16, NORECEIVESHADOW=64), https://wiki.facepunch.com/gmod/Enums/RENDERGROUP и https://wiki.facepunch.com/gmod/ENTITY:DrawTranslucent (проход прозрачных моделей, вызов Draw по умолчанию). API model-материалов, recompute и hologram.setRenderGroup дополнительно сверены с обоими установленными SDK Starfall. Изменение этих настроек само по себе не является игровой проверкой устранения артефакта.

- **0.0.13: Kenney Particle Pack**, Kenney Vleugels: https://kenney.nl/assets/particle-pack — Creative Commons Zero (CC0). Получены PNG `flare_01`, `trace_03`, `light_01` и LICENSE.txt из зеркала https://github.com/Calinou/kenney-particle-pack, commit `ab7086639ee73be31abd87feb21bf1402d4e8144`. Исходники и исходная лицензия в `source-assets/kenney/`. Игровые `vfx_flare_01.png` (39143 байта) и `vfx_trace_03.png` (39767) без изменения, `vfx_light.png` — light_01, уменьшенный Lanczos с 512×512 до 256×256 (31498). Собственные движение/эмиссия/композиция чипа; готовая движковая VFX-система не импортировалась. CC0 относится к этим текстурам, не к аниме-аудио.
